# RFP-014 requirements: evidence, milestones and descopes

Every hard requirement of RFP-014 maps to evidence in this repository (PoC), a proposal milestone (M1–M7),
or an honest descope. The milestones are those of the bid: M1 collateral auctions, M2 price feeds, M3 debt
and surplus, M4 private path and bot SDK, M5 Basecamp mini-app, M6 testnet 0.4, M7 audit.

Dependencies: the runtime, framework, host, token, oracle and authority implementations this engine builds
against, with versions and what happens if one is late, are listed in [README §Dependencies](README.md#dependencies).

Two engines, two evidence columns. The **v04** engine (`v04/`, LEZ v0.4.0-rc1, actor model) is the primary
engine. The **v0.2.4** engine (`programs/`, LEZ v0.2.4) is the engine of the public legacy-testnet run, the
CLI and the Basecamp app; it is kept as public-chain evidence and is byte-frozen (the `rfp014-poc` ImageID).
Both engines share the pure core `crates/auction_core`; a test of that crate is evidence for both and is
listed in both columns. Evidence that belongs to the whole repository rather than one engine (the checker,
the threat model, the design log, the privacy document) is listed in the v04 column. `—` means no evidence
for that engine. The status reflects the stronger of the two engines.

`scripts/check-requirements.py` (CI job `requirements`) fails if a named test, golden file, script, CI job or
document does not exist, if an `#[ignore]`d test is not marked `[ignored]`, or if a required id is missing.
Status meanings: **PoC** shown here; **PoC (partial)** shown here in part, the rest promised in the
milestone named at the end of the row's note; **M#** a proposal milestone; **Descoped** with the reason.

The checker resolves Rust tests by name only. The Basecamp app's QML tests (`apps/auctions/tests/qml`) and the
core module's C++ tests (`modules/auction_engine/tests`) are cited as `doc:` paths, with test names in the notes.
The v04 tests run in the `v04` job of `.github/workflows/v04.yml` (fmt, clippy, `cargo test --workspace`).

The checker proves that evidence exists, not that a CI job has run on a hosted runner. Where a row's
evidence is a CI job that has not yet run on a hosted runner, the row says so in its notes and is at most
**PoC (partial)**.
