Build map · At-risk positions
  • Page, header, tabs, 200px list and panel: unchanged from v3 (AppManagerView grid).
  • Rows: LogosItemDelegate + LogosBadge; scan line uses LogosLink for Rescan.
  • Gauge: Rectangles (track, 150% tick, marker); CR at typography.titleText 30.
  • Quote: inset Rectangle; caps = two stacked LogosProgressBars; states = LogosNotice Warning / Error.
Build map · Bid confirmation
  • Dialog: LogosDialog (backgroundSecondary, border, radiusLarge, scrim), Cancel focused on open, Esc cancels.
  • Buttons: LogosButton Secondary + Primary in rightActions; primary label black.
  • Reveal lists: two inset Rectangles with LogosIcon eye / eye-off.
  • Progress: LogosStageLane (busy = warning pulse, failed = error); 5-block timeout drives the failed state.
