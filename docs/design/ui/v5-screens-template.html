What a new price does

  1. Every position's CR is recomputed against it. Below 150% it shows under At-risk positions.
  2. Live auctions quote bids at the new price straight away.
  3. Outside the allowed range, that collateral type pauses (v4). There is no fallback price.

Build map · Settled
  • Page, list, panel, KPI strip: unchanged from v3.
  • "Where it went": one Rectangle row of three widths (debt, penalty, shortfall) + legend.
  • Claim card: the v4 quote card; disabled reason as in v4 Healthy.
  • Claim goes through LogosDialog + LogosStageLane exactly like a bid.
Build map · System
  • List: four fixed LogosItemDelegate rows, status text in the palette's verdict colours.
  • Coverage chart: two Rectangle bars on one scale + a threshold tick, as the v4 CR gauge.
  • Upkeep rows: LogosButton Secondary, 32px.
  • Frozen: LogosBadge Error in the header, LogosNotice Error on System.
Build map · Dev tools · picker
  • Tab exists only when the backend reports a dev network and the genesis check passed.
  • Price input: LogosTextField with the v3 error style; affected list recomputed by the SDK, not QML.
  • Freeze trigger: Secondary button with error border and label; confirmation dialog repeats the warning.
  • Picker: LogosComboBox-style popup (backgroundSecondary, border, radiusLarge) with v3 selection bar.
